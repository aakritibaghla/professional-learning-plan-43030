# Goal 4 — AI Application Integration Through REST APIs and Model APIs

## Goal and rationale

My goal is to develop practical capability integrating AI functionality into applications through REST APIs and model APIs. The learning plan identifies API usage, application integration, authentication, error handling, testing, and documentation as important components. This is relevant to my career direction because AI engineers need to connect models to usable software systems, rather than only experiment with models in isolation.

## Relevant professional experience

In my AI Researcher role, I have worked on improving prompts for media monitoring and selecting appropriate models for a task. This provides applied exposure to model behaviour and the importance of choosing an appropriate model. It also gives me an opportunity to consider how prompt quality and model selection influence output usefulness.

This experience is related to AI application development, but it is not the same as implementing a REST API integration. I therefore distinguish my current professional exposure from the technical evidence required by this goal.

## Reflection

The goal has helped me identify the components required for a complete integration. A robust application needs to form requests correctly, protect credentials, validate inputs, handle network or service errors, consider rate limits, evaluate responses, and document configuration and usage. Testing should include expected responses as well as invalid inputs and failure cases.

My current evidence supports developing experience with AI prompts and model selection. This portfolio does not claim a completed FastAPI application, deployed model API service, or tested REST integration. Recognising this gap is useful because it makes the next development step specific and measurable.

## Progress assessment

**Status: Partially developed.** Applied AI model selection and prompt refinement are relevant foundations; a hands-on API implementation remains the key evidence gap.

## Continuing professional development

My next practical project should be a small AI-enabled application using a model API. The project should include a clear README, safe configuration of credentials, request and response handling, input validation, error handling, and tests. I will document what the application does, how it is run, and its limitations. I will also evaluate the output and consider privacy and responsible-AI risks. This will connect my existing AI exposure with software engineering and security practices.
