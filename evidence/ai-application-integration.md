# Goal 4 — Integrating AI Through REST APIs and Model APIs

## Why I chose this goal

I want to learn how to connect AI models to applications, rather than only experimenting with models separately. My learning plan focuses on REST APIs and model APIs, including authentication, handling errors, testing, and documenting an application. These skills are relevant to my goal of working in AI engineering.

## Connection to my work

In my AI Researcher role, I have worked on improving prompts for media monitoring and selecting suitable models. This has given me exposure to how model choice and the way a task is described can affect the usefulness of AI outputs.

However, I recognise that working with prompts and selecting models is not the same as implementing an API integration. I want to be clear about that distinction in my progress assessment.

## Reflection

A model API integration involves several parts. The application needs to send requests correctly, protect credentials, validate inputs, handle errors, and make sense of the responses. It also needs testing and documentation so that the application can be understood and used properly.

My current experience gives me a useful starting point, but I still need to demonstrate these technical skills through a project. I have not claimed that I have completed or deployed a FastAPI application or a tested REST API integration in this portfolio.

## Progress

**My progress is partially developed.** My prompt improvement and model selection experience is relevant, but hands-on API integration is still an important area for me to work on.

## What I want to work on next

I want to build a small AI-enabled application using a model API. I would include a README, safe credential handling, input validation, request and response handling, error handling, and tests. I also want to consider privacy and responsible-AI issues while evaluating how well the application works. This would help me connect my existing AI experience with the software development and cybersecurity skills in my learning plan.
