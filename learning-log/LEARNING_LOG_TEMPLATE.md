# Professional Learning Log — Reflection

**Portfolio snapshot:** November 2026  
**Degree:** Bachelor of Artificial Intelligence at UTS  
**Career direction:** AI engineering

## My learning so far

I chose my professional learning goals to help me prepare for a career in AI. They cover ethical AI, cybersecurity, software development tools, and integrating AI models into applications. I think these areas are important because developing an AI system involves more than getting a model to produce an answer. The system also needs to be secure, reliable, and suitable for the people using it.

During my degree, I have worked on a Python calculator and a Java card game. These projects gave me experience writing code and working with different programming languages. I have also used Pandas and KNIME in my learning. In my AI Researcher role, I have been involved in improving prompts for media monitoring and choosing suitable models. This has helped me understand that the model and the way a task is framed can make a difference to the output.

## Ethical and responsible AI

My DesignR coursework involving AI-generated Indigenous Australian imagery was a useful connection to this goal. It made me consider how AI-generated content can represent people and cultures, and why context and cultural sensitivity matter. My learning plan also covers privacy, bias, fairness, transparency, accountability, and Indigenous perspectives and data sovereignty.

I have realised that an AI output might look convincing but still raise ethical concerns. I need to think about where the data comes from, how people are represented, and who might be affected. These considerations are particularly important when AI is used in cultural contexts.

## Cybersecurity

My introductory learning has covered authentication, access control, vulnerabilities, secure coding, and data protection. I can see how these concepts relate to AI applications, especially when an application handles user information or connects to an external model service.

At this stage, I would describe my progress as developing. I have a foundation in the concepts, but I would benefit from applying them in a project. For example, I want to practise handling credentials safely, validating inputs, and thinking about what could go wrong when a request fails.

## Software development tools

The calculator and card game projects gave me programming experience, but I know that writing code is only one part of software development. Testing, debugging, documentation, and version control are also important. I have organised this portfolio in GitHub, which gives me a place to keep the evidence and track changes.

I want to become more consistent with my workflow. Using meaningful commits, writing tests for important functions, and documenting how to run a project would make my work easier for someone else to understand.

## AI application integration

My work involving prompt improvement and model selection has given me some practical exposure to AI. However, I recognise that this is different from building an application that calls a model through a REST API. I still need to practise making requests, handling authentication and errors, testing the application, and documenting it clearly.

Being able to identify this gap is useful because it gives me a clearer direction for my next project.

## Reflection and next steps

Overall, my learning plan has helped me think more carefully about the skills I need for my future career. I have a foundation from my university subjects and projects, and my work has also given me some exposure to AI in practice. I now want to turn more of this knowledge into practical evidence.

My main next step is to build a small AI-enabled application and document how it works. I would like to include tests, safe handling of credentials, and a basic review of the application's ethical and security considerations. This would allow me to work on several of my goals at once and give me a clearer picture of what I still need to improve.
