# Professional Learning Log — Progress Reflection

**Portfolio snapshot:** November 2026  
**Degree:** Bachelor of Artificial Intelligence, UTS  
**Professional direction:** AI engineering

## Learning journey and context

My professional learning goals were selected to complement my Bachelor of Artificial Intelligence and prepare me for responsible, practical work in the AI industry. The goals span ethical AI, cybersecurity, software development tools, and integration of AI models into applications. These areas are related: an AI solution needs to be technically functional, maintainable, secure, and appropriate for the people and communities affected by it.

My university programming experience includes developing a calculator in Python and a card game in Java. These projects gave me opportunities to translate requirements into program logic and work with different programming languages. Coursework and practical exposure to Pandas and KNIME have also supported my understanding of data-oriented workflows. In my AI Researcher role, I have worked with prompt improvement and model selection, which has helped me see that model choice and the quality of instructions can affect the usefulness of AI outputs.

## Ethical and responsible AI learning

The DesignR coursework involving Indigenous Australian imagery brought ethical considerations into a concrete AI context. It prompted consideration of representation, cultural sensitivity, and the potential impact of AI-generated content. My professional learning goal broadens this into privacy, bias, fairness, transparency, accountability, and Indigenous perspectives and data sovereignty. I recognise that ethical practice cannot be reduced to checking whether a model produces a technically plausible output; it also requires consideration of context, affected communities, and how the system is used.

## Cybersecurity learning

The cybersecurity goal focuses on foundational concepts including authentication, access control, vulnerabilities, secure coding, and data protection. These concepts are relevant to AI systems because applications may process user inputs, personal data, model outputs, and external services. My current level is developing: the learning provides a conceptual foundation, while more hands-on practice—such as implementing access controls, testing failure cases, and reviewing security risks—is needed to strengthen practical evidence.

## Software development tools

My Python calculator and Java card game demonstrate programming experience. Building and maintaining projects also makes the value of version control, debugging, testing, and clear documentation apparent. This portfolio itself is organised in GitHub with separate goal-based pages and commit history, giving me a structured place to collect and present learning evidence. My next improvement is to apply a consistent workflow to a software project, including meaningful commits, automated tests, and documentation of design decisions.

## AI application integration

My AI Researcher experience includes improving prompts and selecting appropriate models. This is useful applied AI experience, but it is distinct from building an application around a model API. The integration goal therefore remains partially developed. I need to demonstrate the full application lifecycle: sending a request to an API, handling authentication and errors, validating inputs and outputs, testing behaviour, and documenting how to run the application. This distinction helps me avoid overstating my current achievement.

## Overall reflection

The learning plan has encouraged me to treat professional development as a deliberate process rather than simply completing technical subjects. I have an existing programming and AI foundation, and I can connect it to the professional goals. My strongest insight is that technical ability and responsible practice must develop together. I also see the importance of evidence: a skill is more convincingly demonstrated through a working artifact, tests, documentation, and a reflection on limitations than through a broad statement that I understand it.

My future focus is to build and document a small AI-enabled application, strengthen testing and Git practices, and apply a security and responsible-AI review to the project. This will provide more concrete evidence of progress and support my longer-term career direction in AI engineering.
